Every graphic here is generated inside this repository rather than loaded from a third-party card service. Before each scheduled refresh, [`scripts/sync_avatar.py`](scripts/sync_avatar.py) downloads the current GitHub avatar into `assets/avatar.png`, and [`scripts/make_avatar_ascii.py`](scripts/make_avatar_ascii.py) removes the background and turns it into the self-typing `ascii.svg`. The contribution graphics and section panels are stored in the repository, while the statistics are generated by [`scripts/generate_stats.py`](scripts/generate_stats.py) from GitHub’s GraphQL API and refreshed by [a scheduled GitHub Action](.github/workflows/stats.yml).

The action uses the repository’s built-in `GITHUB_TOKEN`, commits only generated files that change, and deliberately has no `push` trigger so its own commits do not create a loop. The Matrix panels are source-controlled SVG assets generated by [`scripts/make_matrix_headers.py`](scripts/make_matrix_headers.py), so the visual theme remains consistent across GitHub’s light and dark modes.
